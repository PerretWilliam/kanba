# Kanba

macOS SwiftUI app (`./build.sh`). Data: `boards.json` in the data folder (default `~/Library/Application Support/Kanban`; changed from the Projets menu → "Dossier des données…", remembered in UserDefaults; `KANBA_DATA` overrides it).
The app live-reloads this file (manual edits are fine). MCP tools do NOT write to it: they build a proposal in memory (`Store.propose`: base + proposed state), the app shows a diff (click a change for the detail panel) and the user approves (all or change by change). `select_board` and `set_filter` are immediate (screen state).
MCP server `kanban` is built into the app (Streamable HTTP on `http://localhost:47821/mcp`, loopback only, `KANBA_PORT` overrides; code in `Model/MCPServer.swift`, `Model/MCPTools.swift`, tool schemas in `Model/MCPSchemas.swift`, socket glue in `Support/MCPHTTP.swift`). The app must be running. Install: `npx -y add-mcp http://localhost:47821/mcp -g` or `claude mcp add --scope user --transport http kanban http://localhost:47821/mcp`. Tools: get_boards (search/filters; notes only when `board` is given), add_card, add_cards + update_cards (batches, all or nothing), update_card (column = move within the board, to_board = move to another board), delete_card, clear_last_column, reorder_cards, add_column, update_column, delete_column, add_board (initial columns + cards = templates), update_board (rename, closed = hide/reopen a tab), select_board, set_filter (priority/tag/agent/query on the screen: applied in memory, never saved), delete_board, export_board, import_board. Prefer it over editing the file by hand. Tests: `just cover` (100% line coverage of `Model/` and `Support/BoardFile.swift`).

Format: `{"selected": "<board uuid>", "boards": [Board]}`
- Board: `{id: uuid, name, closed?: true (hidden tab, still in the Projets menu; the tab X closes, the trash deletes), parent?: board uuid (set = a phase, i.e. a sub-board of that board; one level only), columns: [{id, name, color}], cards: [Card]}`; colors: gray blue green orange purple pink teal red; the last column means "done".
- Card: `{id: uuid (new uppercase uuid4), title, notes, priority: 0|1|2 (low/medium/high), due?: seconds since 2001-01-01 UTC, status: column id, tags: [string], agents?: [{name, model?, effort?}]}`. `agents` = assignees (several allowed): `name` is an AI (claude, codex, chatgpt, gemini, copilot, cursor, windsurf, mistral, deepseek, grok, perplexity, llama, qwen, kimi, zed, cline, aider, opencode, goose, or any text) or `me` (the user); `model` free text; `effort` minimal|low|medium|high|xhigh|max. `notes` is Markdown (rendered in the card side panel opened by clicking a card). get_boards also filters by `agent`.
- Card order within a column = order in the `cards` array (top = highest priority); the app does not sort. `priority` is just a label.
- Invalid JSON = change ignored. `boards` may be empty (the app then shows its welcome page).
